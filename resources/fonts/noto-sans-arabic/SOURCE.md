# Noto Sans Arabic

Locally served variable font from the official google/fonts repository, ofl/notosansarabic/NotoSansArabic[wdth,wght].ttf. Retrieved 2026-11-17. License: accompanying OFL.txt. No runtime third-party font requests.

Web subsets (2026-11-19): `NotoSansArabic-arabic.woff2` and `NotoSansArabic-latin.woff2` are generated from the TTF above with fonttools (axes pinned to wdth=100, wght 300-800; subset by unicode range; woff2). The full TTF is kept only for PDFs (`config/brand.php` `font.file`). OFL.txt applies to all three files.
