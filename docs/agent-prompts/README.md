# مجموعة برومبتات الوصول بالمشروع لأفضل حالة

كل برومبت بيبدأ بسطر بيقول للـ agent يقرا `00_COMMON.md` الأول. الملف ده فيه كل القواعد المشتركة: الريبو الصح، أوامر التشغيل، المعمارية، قاعدة "مفيش اختبارات من الـ implementer"، الـ git، والـ board.
افتح كل برومبت في session جديدة على الريبو، وانسخ محتوى الملف زي ما هو.

## ترتيب التشغيل

| الموجة | البرومبتات | تشتغل إزاي | ليه |
|---|---|---|---|
| 1 | **01** Regression | لوحده، **الأول** | بيعدّل كود في أماكن كتير. لازم الـ suite تبقى خضرا قبل أي حاجة تانية. |
| 2 | **02** Evidence audit · **03** Security review · **07** Demo rehearsal | **مع بعض** (التلاتة قراءة بس) | بيطلعوا قايمة المشاكل الحقيقية اللي هتغذي الموجة 3. |
| — | مراجعة الـ PO | أنا | أراجع التقارير، وأوافق على اللي يتصلّح، وأرفض الادعاءات اللي من غير دليل. |
| 3 | **04** Fix findings → بعده **05** Commerce و**06** Learning مع بعض | 04 لوحده، وبعدين 05 و06 مع بعض (الملفات منفصلة) | تصليح الثغرات والفجوات الوظيفية. |
| — | اختبارات | مودل الاختبارات | يكتب الاختبارات من الـ test prompts اللي اتولدت في `docs/test-prompts/`. |
| 4 | **08** Performance · **09** A11y/RTL | واحد ورا التاني، أو مع بعض لو الملفات منفصلة | جودة. |
| 5 | **11** P10 pre-work · **12** Production readiness · **13** Guides · **14** Runbook | **مع بعض** | تجهيز للإطلاق، ومش مستني O-003. |
| 6 | **15** Gate closure | أنا (الـ PO) | قفل الـ gates بالأدلة. |
| اختياري | **10** Design polish | بعد الموجة 3 | تحسين التصميم فوق اللي اتقبل. |

## النتيجة المتوقعة
- Suite خضرا، و board بيوصف الحالة الحقيقية، والثغرات High/Critical متقفلة، والفجوات الوظيفية المعروفة متصلّحة.
- ديمو J01–J12 شغال بالعربي والإنجليزي، وأداء ووصولية مقاسين.
- framework نقل البيانات جاهز، وكمان runbook وأدلة تدريب وconfig إنتاج.
- Gates من P0 لـ P9 متقفلة على أدلة.

## اللي مش هيتحل من غيرك (owner inputs)
O-003 الوصول للنظام القديم، O-001 الدومين، O-006 Paymob، O-007 البيانات القانونية والضريبية، O-013 الكيان السعودي، O-014 مفتاح OpenAI، وقرار الـ fast-forward لـ `main`.
