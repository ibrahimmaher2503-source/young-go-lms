# Young Go — حزمة الريفيرنس البصري

المجلد يجمع **28 صورة جديدة** مبنية على الـPRD وبنفس الاتجاه الذي اختاره المالك، مع الصورة الأصلية: 24 شاشة ديسكتوب عربية، شاشة English/LTR، نسختا موبايل، ولوحة للعناصر المشتركة.

- [افتح معرض الصور](index.html) — اضغط أي صورة لفتحها كاملة.
- [الفهرس وربط الشاشات بالـPRD](PAGE_MAP.md).
- [المكونات المشتركة وحالة الكود](COMMON_COMPONENTS.md).
- [manifest.json](manifest.json) هو قائمة الملفات النهائية: المسار، اللغة، العائلة، المتطلبات، المكونات، الأبعاد وSHA-256.
- [generation-manifest.json](generation-manifest.json) يحفظ الـprompts الفعلية وتصحيحاتها ومصدر كل مخرج. استُخدمت أداة imagegen المدمجة؛ لم يُستخدم CLI أو API key.

## الاستخدام في التنفيذ

1. اقرأ AGENTS.md ثم PRD/مواصفات المهمة، وVISUAL_ACCEPTANCE.md.
2. اختر أقرب شاشة من manifest.json، وحدد مكوناتها من COMMON_COMPONENTS.md قبل كتابة الواجهة.
3. استخدم نفس tokens والمكونات الموجودة؛ الجداول تبقى Filament أصلية داخل WorkspaceListRecords. واجهات الطالب والزائر لها تنقلها المخصص مع نفس المكونات البصرية.
4. ابنِ النصوص والحالات والصلاحيات من الـPRD والكود الموثق، ثم قارن لقطة المتصفح بالمرجع المناسب على مقاس مماثل، في AR/EN والموبايل والديسكتوب.
5. أي فرق بصري غير مبرر يظل مفتوحًا؛ الاختبارات أو الصورة وحدها لا تثبت أن الرحلة تعمل. احتفظ بالريفيرنس الأصلي ولا تستبدله بلقطة التنفيذ لمجرد تمرير المراجعة.

## ما الذي توضحه الصور؟

الهيدر، التنقل، شبكة الكروت، شريط الملخص، الجداول والبحث والفلاتر، النماذج والمعالج، بطاقات الدورات والتقدم، المنهج وPDF، المشغل والمساعد المقيد بالدرس، طلبات المساعدة، المالية، الدفع والاختبار. النسخة الإنجليزية توضح انعكاس LTR، والموبايل يوضح إعادة ترتيب المحتوى لا تصغيره فقط.

## حدود مهمة للـAI agent

- هذه **مراجع تصميم، وليست ميزات منفذة أو بيانات حقيقية**. لا تُنشئ مسارات أو جداول أو صلاحيات أو حالات جديدة لأن الصورة عرضتها. الـPRD والقرارات أعلى أولوية من النصوص والأرقام داخل الصور.
- الأسماء والأرقام والأسعار والتواريخ والأسئلة والأجوبة وأرقام صفحات PDF أمثلة. لا تتحول إلى seed أو أسعار أو نتائج أو دليل grounding. المساعد الحقيقي يجب أن يقرأ ملف الدرس المعتمد بالفعل.
- حدود الأعمار وسياسات القاصرين والعمولات والضرائب والاشتراكات ومفاتيح الدفع لا تُستنتج من الصور. O-027 للهوية الرسمية لا يُغلق بواسطة الشعار المرسوم.
- المساعد مصوّر لحالة متعلم بالغ مؤهل داخل درس مسجّل فقط. لا يظهر في البث المباشر أو الاختبار أو كدردشة عامة. لا تعرض لوحة ولي الأمر تاريخ محادثات الابن.
- في صورة11 تظهر لوحة التحويل اليدوي كحالة بديلة موضحة؛ التنفيذ يعرضها فقط عند اختيار التحويل اليدوي. إثبات الدفع قيد المراجعة لا يمنح وصولًا.
- شريط العرض الصغير «01 · تنظيم هادئ» في بعض الصور جزء من تقديم الريفيرنس، وليس عنصرًا داخل المنتج.
- لا تنسخ أخطاء صياغة أو نسب/عدّادات توضيحية من raster إلى المنطق. التقدم والأعداد والترقيم والحالات تُحسب من المصدر الحقيقي.
- الملفات الموجودة في drafts نسخ مستبدلة؛ استخدم فقط الصور المدرجة في manifest.json.

الصور لا تدّعي تغطية كل صفحة/حالة في الـPRD. PAGE_MAP.md يوضح العائلات القابلة لإعادة الاستخدام؛ التدفقات الأخرى تحتاج مرجعًا خاصًا قبل اعتبارها مقبولة بصريًا.
