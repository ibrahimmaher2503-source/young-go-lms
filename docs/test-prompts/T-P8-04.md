- A1 Duplicate reference cannot be approved twice: two proofs with the same reference (any case/spacing) cannot both be pending/approved (second submit refused with `reference_taken`, also across different orders and payers); approve then approve again creates one order paid transition, one `entitlement` row, one `manual_payment.approved` audit; a rejected reference can be resubmitted once.
