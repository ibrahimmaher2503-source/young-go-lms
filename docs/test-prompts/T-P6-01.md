## Rules (QuestionRules)
- `single`: 2 to 8 non-empty options, exactly 1 correct.
- `multiple`: 2 to 8 options, at least 1 correct and at least 1 wrong.
- `true_false`: needs `true_is_correct` (bool, null refused); creates two options "True/False" in both languages with exactly one correct.
- `short_answer`: 1 to 10 accepted answers (each stored as a correct option; the UI forces `is_correct = true`); empty rows are ignored.
- `essay`: no options stored even if some are sent.
- Common: prompt needs text in ar or en; points 0.25 to 1000 (rounded to 2 decimals); explanation optional; unknown type refused; text trimmed; whitespace-only values count as empty; empty option rows are dropped before counting.

## Acceptance
- A1 Validation per type (e.g. single choice has exactly one correct).
- A2 An instructor is scoped to assigned courses.
