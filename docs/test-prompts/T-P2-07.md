## What was built
- Tables (migration `2026_11_17_480000_create_blog_tables.php`): `blog_categories` (name/description JSON, `slug_ar`, `slug_en`, sort, status active|inactive, search_text), `tags` (name JSON, slugs, search_text), `blog_posts` (category nullable, author nullable -> users, slugs, title/excerpt/body/featured_image_alt/seo_title/seo_description JSON, featured_image path on the `public` disk, status draft|scheduled|published, `published_at`, search_text), pivot `blog_post_tag` (`blog_post_id`, `tag_id`). Models `BlogPost`, `BlogCategory`, `BlogTag` (table `tags`) in `app/Models`; `BlogPostStatus` enum.
- Public rule: `BlogPost::live()` = status in (scheduled, published) AND `published_at` not null AND `published_at <= now()`. A scheduled post appears by itself, no job needed (use `Carbon::setTestNow`).
- `SaveBlogPost($actor, ?$post, $data)` (`app/Domain/Content/Actions`): authorizes `content.blog.manage`; `tags` = list of tag ids (synced); scheduled needs a future `published_at` (else `ValidationException` key `published_at`, except re-saving an already-scheduled post with the same time); published with empty time gets now; published with a future time is stored as `scheduled`; audit events `blog.post_created`, `blog.post_published`, `blog.post_scheduled`, `blog.post_unpublished` (to draft), `blog.post_updated`. `SaveBlogCategory` -> `blog.category_saved`, `SaveBlogTag` -> `blog.tag_saved`. Slug format/uniqueness is validated by the Filament form, not the action.
- `PublicBlog` (`Content/Queries`): `posts(['q','category','tag'])` paginated 9/page, newest first, category/tag are slugs of either language (inactive category or unknown slug = no results), `q` matches `search_text` (Arabic-normalized); `find($key)` by either slug or numeric id, live only; `related($post)` (same category or shared tag, excludes itself, live only); `categories()` (active with a live post); `tags()`; `keyFor($model, $locale)`.
- Routes: `GET /blog` (`blog.index`), `GET /blog/{post}` (`blog.show`), and prefixed `/ar/blog`, `/en/blog/{post}` (`public.blog.*`). Draft, future-dated and unknown posts answer 404. Index validates `q` (max 160), `category`, `tag` (max 120).
- SEO (`BlogSeo`): index has `Blog` JSON-LD, canonical `/{locale}/blog`, robots `noindex, follow` when any filter or page > 1, else `index, follow`; article has `Article` JSON-LD (headline, datePublished, dateModified, author Person, publisher Organization, image when set) plus `BreadcrumbList`, `og:type=article`, `og:image` when set, canonical = prefixed URL of the active locale, hreflang only for locales that have their own title, plus `x-default`. Per-locale `seo_title`/`seo_description` win, else title/excerpt/body.
- Sitemap: `SitemapEntries` lists the blog index (both locales) and live posts with alternates and `lastmod`; never drafts or future posts. `SeoServiceProvider` drops the cached sitemap when a `BlogPost` is saved or deleted; `routes/console.php` drops it hourly (`seo:sitemap-scheduled-posts`).
- Admin (panel `admin`, gate `content.blog.manage`): Filament resources `BlogPostResource`, `BlogCategoryResource`, `BlogTagResource` (list page with create and edit modals, AR/EN tabs). Audit labels in `lang/{ar,en}/audit-events.php` for every `blog.*` event.

## Tests to write (Feature, `tests/Feature/Blog/`)
1. **A1 Scheduled visibility**: a scheduled post with future `published_at` is 404 on `/blog/{slug}`, absent from `/blog`, absent from `sitemap.xml`; after `Carbon::setTestNow(published_at + 1 minute)` it is 200, listed and in the sitemap. A draft is never public even with a past `published_at`. Published post: 200 in AR and EN prefixed URLs.
2. **Action rules**: scheduled without time or with a past time throws; published without time gets now; published with future time becomes scheduled; audit event name per transition (assert `Activity` rows, `log_name` `audit`, causer is the actor); user without `content.blog.manage` gets `AuthorizationException`; tags sync replaces the set.
3. **Index filters**: category by AR slug and EN slug, tag, text search (Arabic with and without diacritics/alef variants), combination, unknown category -> empty state, inactive category hides the filter and the badge, pagination (10 posts -> 9 + 1), `q` longer than 160 -> 302/422 validation.
4. **Article page**: shows title/body/author name/category/tags in the active locale, escapes HTML in title and body (no raw `<script>`), related posts exclude itself and drafts/future posts, featured image `alt` per locale, article 404 for unknown key, numeric id works.
5. **SEO**: article head has canonical = `/{locale}/blog/{slug}`, hreflang ar/en/x-default (only locales with a title), one `Article` and one `BreadcrumbList` block, `og:type` article; index robots `noindex, follow` with `?category=x` or `?page=2`, `index, follow` plain. Sitemap contains blog index and post URLs with `xhtml:link` alternates.
6. **Filament** (Livewire tests as in `tests/Feature/Pages/CmsPagesTest.php`): admin sees the three resources; instructor/finance do not (404/403); creating a post through the create modal with both languages saves, syncs tags and defaults the author; scheduling without a time shows an error on `published_at`; duplicate slug is rejected.
7. **AR/EN parity and RTL**: `php artisan app:check-translations` and `app:check-rtl` pass; add a browser/screenshot test (`tests/Browser`) for `/ar/blog` and `/en/blog` desktop and mobile if the matrix supports it (G7).
