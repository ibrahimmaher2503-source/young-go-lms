## What was built
- Routes (`routes/web.php`): `GET /courses/{course}` name `catalog.show` (`PublicCourseController`), `GET /courses/{course}/preview/{item}` name `catalog.preview` (`PublicCoursePreviewController`, `item` numeric). `{course}` is the AR slug, the EN slug or the numeric id.
- `App\Domain\Catalog\Queries\PublicCourseDetail`: `find($key)` returns only `status = published` courses (with category and active instructors); static `key($course)` = slug of the active locale, else the other slug, else id; `curriculum($course)` returns published sections/items (via `CurriculumOutline::forStudents`) with `sections[].items[]` = id, title, type, minutes, preview; plus `lessons`, `minutes`, `preview_item` (first preview lesson item id or null).
- `App\Domain\Catalog\CourseSeo::for($course, $url, $lessons)`: `title`/`description` use `seo_title`/`seo_description` of the active locale, falling back to title and short description (then stripped description, max 300 chars); `canonical` = `canonical_url` when set else `$url`; `keywords`; `og` (og:type, title, description, url, locale `ar_EG`/`en_US`, site_name); `jsonld` Course (`@type`, name, description, url, inLanguage, educationalLevel, provider, instructor[] Person, numberOfLessons).
- `EntitlementService::canPreviewPublicly(CurriculumItem)`: allow only when the course is `published`, the item and its section are published and the item is a non-archived Lesson with `is_preview`; otherwise deny (`course_unpublished`, `item_unpublished`, `not_entitled`). Works without a user.
- Migration adds JSON `seo_title`, `seo_description`, `seo_keywords` and string `canonical_url` to `courses` (Course model: translatable + fillable).
- Views `catalog/show`, `catalog/preview`, `catalog/_cta`; layout `x-layouts.base` got props `wide` and `indexable` (when `indexable`, the page's `head` slot replaces the default `noindex` meta; every other page still gets `noindex, nofollow`).
