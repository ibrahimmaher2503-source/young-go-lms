## What was built

Existing `access` = free|paid|subscription unchanged. Price sort: free = 0, no price (subscription only) always last; ties newest first. Popular = active learners per course from `EnrollmentReport::activeCountsByCourse()` (top 200, Entitlements module only), ties and zero-count courses newest first.
- `CohortAvailability` (`app/Domain/Cohorts`): `constrain()` for the filter and `forCourses()` for card badges. open = no cohorts at all, or an open cohort (status open, Cairo-date enrolment window) with room (capacity null or seated < capacity), and not subscription-only; seats = open cohort with capacity and room; soon = open cohort starting within 14 days from today; subscription = access_mode subscription_only or both. Badges: seats left (smallest among open limited cohorts), starts date, open, `Enrolment closed` (cohorts exist, none open with room), subscription. `Course::cohorts()` added.
- `CheckoutOffers::coursePrices()` batches one `course_prices` query for the page; card shows `<x-ui.price>` (EGP in the market format) only for individually sold, published, priced courses; free keeps the Free badge.
- `CatalogSeo` + `catalog/index`: base catalog (no search/filter/sort, page 1, at least one course) = `index, follow`; anything else `noindex, follow`; canonical is always `/{locale}/courses`; hreflang ar/en; JSON-LD CollectionPage + ItemList + BreadcrumbList. - UI: filters partial (desktop card, mobile modal) gained price min/max, sort, availability; active-filter chips with remove links (`data-active-filters`) and "Clear all"; empty state uses `x-ui.empty-state` (`data-catalog-empty`). All state is in the GET query string; pagination keeps it (`appends`). `price_min > price_max` is swapped; `sort=newest` is dropped from the active filters.
