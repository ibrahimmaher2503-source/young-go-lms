## What was built

The category intro text is the existing translatable `description`.
- Model `InstructorProfile` (constants APPROVED/DRAFT/HIDDEN; `publicName($locale)` = profile display name, then account `display_name`, then account `name`). `Category` gained the three SEO fields (translatable and fillable).
- `PublicInstructors` (`app/Domain/Instructors/Queries`): `query()` is the single definition of public = profile status `approved` AND user `status = active` AND user holds role `instructor_academy` or `instructor_independent`. `find($key)` by slug of either language or numeric id; `forUsers($ids)` keyed by user id; `keyFor()`. `PublicCategory` (`Catalog/Queries`): `find($key)` active categories only; `children()` (active, with a published course); `listed()` (active categories that hold, or whose child holds, a published course); `keyFor()`.
- `SaveInstructorProfile($actor, ?$profile, $data)` (`Instructors/Actions`): needs gate `instructor.manage` (admin, super_admin); account must hold an instructor role (else `ValidationException` key `user_id`); `disciplines` = category ids, synced; moving to `approved` stamps `approved_at`/`approved_by`; audit events `instructor_profile.approved`, `.hidden` (leaving approved), `.saved`.
- Routes (unprefixed in `routes/web.php`, prefixed `/ar|en/...` in `routes/seo.php`): `GET /categories/{category}` (`categories.show`, `public.categories.show`) and `GET /instructors/{instructor}` (`instructors.show`, `public.instructors.show`). 404 for unknown/inactive category and any non-public profile. Courses listed come from `CatalogQuery::matching` (published only; a parent category also lists its sub-categories' courses), 12 per page.
- SEO: `CategorySeo` (CollectionPage + ItemList of the page's courses + BreadcrumbList; canonical = prefixed URL; hreflang ar, en, x-default; robots `noindex, follow` when page > 1 or no courses, else `index, follow`; per-locale `seo_title`/`seo_description`/`seo_keywords` win over name/description). `InstructorSeo` (Person: name, url, description from bio, jobTitle from headline, image = avatar when set, knowsAbout = disciplines, worksFor Organization; BreadcrumbList; og:type `profile`; hreflang ar/en/x-default). No email, phone, username, `name_ar`, `name_en` anywhere.
- Sitemap (`SitemapEntries`): active categories with a published course, and public profiles, each with ar/en alternates + x-default and `lastmod`. `SeoServiceProvider` drops the cached sitemap on `Category` and `InstructorProfile` saved/deleted, and on `User` saved only when `status` changed.
- Course page: instructor names (hero badge text unchanged, plus the `#instructor` card) become links (`data-instructor-link`) to the profile only when that profile is public; `CourseSeo` adds `url` (and the public name) to each `Person` instructor of the Course JSON-LD only for public profiles.
- Admin (panel `admin`, gate `instructor.manage`): `InstructorProfileResource` (list + create/edit modals, AR/EN tabs, user select limited to instructor roles and locked on edit, status, disciplines, avatar, SEO). `CategoryResource` form now has the shared SEO group (no canonical) and the edit modal loads the SEO translations. Audit labels in `lang/{ar,en}/audit-events.php`; new `lang/{ar,en}/instructors.php` and `category_page.php`.

## Tests to write (Feature, `tests/Feature/Instructors/` and `tests/Feature/Catalog/`)
1. **A1 Instructor 404 matrix**: approved profile of an active instructor = 200 in `/instructors/{slug}`, `/ar/...` and `/en/...`; 404 for draft, hidden, suspended/inactive user, user who lost the instructor role, unknown slug. Numeric id works.
2. **No PII**: HTML and every JSON-LD block of the profile and category pages contain no email, phone, username, `name_ar`/`name_en`; name is profile `display_name`, falling back to account name; bio of the other language is never shown as fallback.
3. **Profile content**: shows headline, bio (HTML escaped, `nl2br`), avatar (when set), discipline chips linking to category pages (only active categories), only that instructor's published courses (no draft/private/archived/upcoming/suspended); empty state text when none; pagination 12.
4. **A2 Category page and sitemap**: category with a published course: `/categories/{slug}` 200 (both slugs, AR and EN prefixed), lists published courses only, includes sub-category courses, sub-category chips only for active children with published courses; inactive or unknown category 404. `sitemap.xml` contains the category URL for ar and en with `xhtml:link` ar, en, x-default and `lastmod`; an empty category, an inactive category, an unapproved or hidden profile are absent; an approved profile is present.
5. **SEO**: category head has canonical = prefixed URL, hreflang, one `CollectionPage` and one `BreadcrumbList` block, `noindex, follow` on `?page=2` or no courses, `index, follow` otherwise; per-locale SEO title/description override the name/description. Profile head has `Person` JSON-LD, hreflang, `og:type` profile.
6. **Course page link**: instructor name links to the profile only when public (approved + active + role); otherwise plain text; Course JSON-LD `instructor` entries carry `url` only for public profiles.
7. **Sitemap cache**: after building the sitemap, saving a `Category`, saving/deleting an `InstructorProfile`, or changing a user's `status` drops the cache; a plain `last_login_at` update does not.
8. **Action**: `SaveInstructorProfile` throws `AuthorizationException` without `instructor.manage`; rejects an account without an instructor role (`user_id`); approving sets `approved_at`/`approved_by` and audits `instructor_profile.approved`; leaving approved audits `.hidden`; disciplines sync replaces the set; re-saving while approved keeps `approved_at`.
9. **Filament** (Livewire tests as in `tests/Feature/Pages/CmsPagesTest.php`): admin sees `InstructorProfileResource`; instructor and finance panels do not; create modal saves with both languages and discipline; duplicate slug rejected; category edit modal shows existing SEO values and saves new ones without wiping others.
10. **AR/EN parity and RTL**: `php artisan app:check-translations` and `app:check-rtl` pass. Add browser/screenshot tests (`tests/Browser`) for `/ar` and `/en` category and instructor pages, desktop and mobile, light and dark if the matrix supports it (A3, G7). ## Owner decisions to confirm (safe defaults applied)
- Public profile is admin-managed only (`instructor.manage`); instructors cannot edit or approve their own (needs a decision, could join the instructor panel later).
- Disciplines are links to categories (no free-text list); category intro = `description`.
- Sitemap lists only categories with at least one published course, and profiles regardless of whether they have courses.
- A profile is public only while the account is active and keeps an instructor role.
- Instructor reviews are out of scope.
