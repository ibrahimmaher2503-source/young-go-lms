## What was built
- Routes in `routes/seo.php` (registered in `bootstrap/app.php`): `GET /robots.txt` (`seo.robots`), `GET /sitemap.xml` (`seo.sitemap`), and locale-prefixed public pages under `/{ar|en}`: `/`, `/courses`, `/courses/{course}`, `/courses/{course}/preview/{item}`, `/pages/{slug}` (names `public.home`, `public.catalog.index`, `public.catalog.show`, `public.catalog.preview`, `public.cms.show`). They reuse the same controllers as the unprefixed routes (which keep working); `SetLocale` takes the locale from the prefix and `ForgetPublicLocale` removes the parameter.
- `App\Domain\Seo\PublicUrl`: `home/catalog/course/page($x, $locale)` build absolute prefixed URLs (course key = slug of that locale, else the other slug, else id; `PublicCourseDetail::keyFor`), `localesWithTitle($model)` (locales with a non-fallback title), `alternates($urls)` adds `x-default` (default locale or first).
- `App\Domain\Seo\PageSeo`: `make`, `page(CmsPage)`, `home()`, `breadcrumbs()`; array keys `title description keywords robots canonical alternates og og_alternate jsonld extra_jsonld`. `CourseSeo::for()` returns the same shape (canonical = `canonical_url` when set, else the prefixed URL of the active locale; alternates only for locales in which the course has its own title; `extra_jsonld` = BreadcrumbList).
- `<x-seo.head :seo>` prints description, keywords (only when set), robots, canonical, `hreflang` alternates, OG tags, `og:locale:alternate`, and one `application/ld+json` per block (JSON hex-escaped). Used by the course page (Course + BreadcrumbList = two blocks), CMS pages (WebPage), the home page (Organization + WebSite). Those pages are `index, follow`; CMS preview, `/courses`, learner/auth pages stay `noindex, nofollow`.
- Sitemap: `BuildSitemap` (cached under `config('seo.sitemap_key')`, ttl 1 day, dropped on `Course`/`CmsPage` saved/deleted by `SeoServiceProvider`; `php artisan seo:sitemap` rebuilds, scheduled daily 02:30). Entries (`SitemapEntries`): home (both locales), published courses and published CMS pages, one `<url>` per locale that has its own title, each with `xhtml:link` alternates (all languages + x-default) and `lastmod`. No draft/pending_review/private/upcoming/suspended/archived course, no draft page, no catalog listing, no learner/staff URL. Categories and blog are not listed yet (no public pages until T-P2-09 / T-P2-07).
- robots.txt (`config/seo.php`): `seo.indexing` (env `SEO_INDEXING`, default true only when `APP_ENV=production`). When off: `Disallow: /`. When on: `Disallow:` lines for admin, instructor, finance, my, learn, family, profile, link, security, guardian, files, media, api, assistant, login, register, forgot-password, reset-password, email, verify, locale, livewire, _design, up; `Allow: /`; `Sitemap: <url>/sitemap.xml`. `public/robots.txt` was deleted so the route answers.
- Redirects (ED-018): table `seo_redirects` (`from_path` unique, `to_path`, `status_code` default 301), model `SeoRedirect`, `ResolveRedirect::for($path)` (matches raw and percent-decoded path; only targets starting with a single `/`; status 301/302/307/308, else 301; same-path target ignored). `LegacyRedirectController` is the `Route::fallback`: a GET that no route matches and that is in the table redirects (query string appended when the target has none), otherwise 404.
- Locale switcher (`x-ui.locale-switcher`): on `/ar/...` or `/en/...` it posts `return_to` with the prefix swapped; if the path has characters the `/locale` rule rejects (percent-encoded Arabic slug) it returns to `/{locale}`.
- Lang `seo.home_description` AR and EN (placeholder copy, O-027).

## Acceptance
- A1 Sitemap excludes drafts, private and learner areas: with a published course (AR+EN titles), a published page, and one course per other status plus a draft page, `GET /sitemap.xml` is 200 `application/xml`, parses as XML, contains the published ones (`/ar/courses/<ar slug percent-encoded>`, `/en/courses/<en slug>`, `/en/pages/<slug>`, `/ar`, `/en`) and none of the others, nor `/admin`, `/my`, `/learn`, `/courses` (listing) or `/media`. A course with only an English title is listed only under `/en`. Publishing a draft (`PublishCourse`) shows up in the next request (cache dropped); unpublishing removes it. `seo:sitemap` exits 0 and refreshes. robots.txt disallows every private prefix and names the sitemap when `seo.indexing` is true; is `Disallow: /` when false.
- A2 hreflang/canonical on the course page: `GET /en/courses/<en slug>` has `<link rel=canonical href=".../en/courses/<en slug>">`, `hreflang="ar"` to `/ar/courses/<ar slug>`, `hreflang="en"`, `hreflang="x-default"` (default locale), `og:url` = canonical, `og:locale` `en_US`, `og:locale:alternate` `ar_EG`; the `/ar/...` page mirrors it with `dir=rtl`, `ar_EG`. `canonical_url` set on the course overrides canonical but not hreflang. An unprefixed `/courses/<slug>` still answers 200 and its canonical is the prefixed URL. A non-published course under a prefix is 404.
