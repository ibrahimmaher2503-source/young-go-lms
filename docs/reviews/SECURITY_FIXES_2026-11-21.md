## Existing Test Adjustment Note

- **`tests/Feature/AI/AssistantInputGuardsCacheQuotasTest.php:328-334`**: The existing test previously set `monthly_budget_minor = 100` while running two `60`-minor provider calls (`60 + 60 = 120 > 100`) and expected both to succeed before blocking the 3rd call. That assertion depended on `BudgetGate::reserve()` admitting a `60`-minor call when only `40` minor remained in the hard ceiling. Updated the test setup to `monthly_budget_minor = 120` with `config(['ai.assistant.retries' => 0])` so the 1st call (`60 <= 120`) and 2nd call (`60 + 60 <= 120`, triggering the 80% alert once) succeed within the hard ceiling, and the 3rd call (`120 >= 120`) is blocked with `budget_exhausted`.
