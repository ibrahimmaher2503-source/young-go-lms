## Comparison Notes
1. **Instructor Queue Workspace**:
   - Reuses `WorkspaceListRecords` matching D-026 and `TABLE_WORKSPACE.md`.
   - Summary strip displays 3 scoped metric items (Open, Awaiting Instructor, Overdue).
   - Overdue badge highlights overdue requests requiring attention.
   - Filters (course, status, overdue) match the PRD §16 specification.
2. **Request Detail View**:
   - Shows complete context card: student, course, lesson, status badge, overdue indicator, due SLA date, video position with direct preview link, source PDF pages, and document version.
   - Displays AI question and answer cards with `dir="auto"`.
   - Thread card displays chronological staff and student responses.
   - History card displays state transitions and audit events.
   - Safeguarding flags section is restricted to staff with `ai.conversation.view`.
3. **Learner Thread**:
   - Clean, accessible card layout with `[data-help-thread]`, `[data-help-message]`, and state-dependent controls.
   - Form is displayed only when status is `instructor_replied` or `waiting_for_student`.
   - In `new` and `in_progress` states, a polite waiting message is shown.
   - In `resolved` and `closed` states, the thread is marked as closed.
   - Parent access policy correctly hides private conversation context while showing instructor responses.
4. **Accessibility (Axe Clean)**:
   - All captured pages pass Axe accessibility checks (`wcag2a`, `wcag2aa`).
