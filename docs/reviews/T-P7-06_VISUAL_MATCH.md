## Comparison Notes

### 1. Assistant Controls (`/admin/assistant-controls`)
- **Reference**: `01-admin-overview-v2.png` (cards, badges, metric lists) and `18-shared-component-library-v2.png`.
- **Global switch**: Rendered with state badge (`data-global-state="off"`) and primary button (`data-action="enable"`).
- **Readiness Checklist**: Displayed in structured list items with status dots (`.yg-ai-dot`) mapping to `ok` (green), `todo` (amber), and `info` states.
- **Provider Health Table**: Lists primary route and fallback route; circuit state dot indicates `open` (red) with reset circuit action button (`data-reset-circuit="fake"`).
- **Settings Cards**: Provider, quotas, and retention cards display key-value metrics with action buttons opening Filament modals.
- **Modals**: Provider, Quotas, Retention, and Enable action modals open upon button click, trap focus, and dismiss upon `Escape` key.

### 2. Usage Report (`/admin/assistant-usage`)
- **Reference**: `01-admin-overview-v2.png` (summary tiles) and `18-shared-component-library-v2.png`.
- **Summary Tiles**: Grid `.yg-ai-tiles` displays requests, answered, not in source, cache hits, guard blocks, error counts with percentages, cost, latency (avg/p95), and token counts.
- **Tables**: Breakdown by day (with bar tracks), by result type, by lesson, and by model.
- **Responsive scrolling**: Tables wrapped in `.yg-ai-scroll` to prevent horizontal page overflow at 390px viewport (`document.documentElement.scrollWidth <= window.innerWidth`).
- **Anonymity**: Zero student identities, conversation IDs, hashes, or message texts are exposed.
- **Empty State**: When no data matches the range, clean card displays `[data-usage-empty]`.

### 3. Lesson Insights (`/admin/assistant-insights`)
- **Reference**: `01-admin-overview-v2.png` and `18-shared-component-library-v2.png`.
- **Filters**: Lesson selector dropdown and date range pickers.
- **Summary Tiles**: 5 core metrics (questions, answered, not in source, not understood feedback, simpler requests).
- **Gaps & Topics**:
  - Gaps section (`[data-section="gaps"]`) highlights unaddressed student questions preceding `not_in_source` results with frequency counts.
  - Topics section (`[data-section="topics"]`) lists approved key terms found in questions.
  - Cited pages (`[data-section="pages"]`) displays top referenced PDF pages.
- **Empty State**: Displays prompt to select a lesson when unselected.

### 4. Availability Management (`/admin/assistant-availability`)
- **Reference**: `03-curriculum-builder.png` (lesson list items and status badges).
- **Course Toggle**: Switch control to toggle course-wide assistant status.
- **Curriculum Lesson Rows**: Lists each video/audio lesson with type badge, PDF readiness status chip (`ready`, `awaiting_approval`, `processing`, `failed`, `none`), and individual switch button (`data-lesson-switch`).
- **Overflow**: Table horizontally scrolls within `.yg-ai-scroll` without breaking mobile page container.

## Findings and Deviations (G7 Review)

1. **Accessibility Bug (BUG-P7-06-01)**:
   - In `resources/views/filament/ai/availability.blade.php` (lines 29, 53), switch buttons use `role="switch" aria-pressed="..."` instead of `aria-checked="..."`. Axe flags this as critical violations (`aria-allowed-attr` and `aria-required-attr`).
   - The accessibility test is skipped and logged in `docs/reviews/BUGS_FOUND.md` per task instructions.
2. **Tabular Numerics**:
   - Numbers across tiles and tables use tabular figures via `.yg-ai-num` to prevent numeric jitter and maintain alignment in both LTR and RTL.
3. **WCAG Compliance on Controls, Usage, and Insights**:
   - Axe accessibility audit reports 0 violations across Controls, Usage Report, and Insights in both Arabic (RTL) and English (LTR), in both light and dark themes.
