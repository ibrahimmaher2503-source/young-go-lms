# G7 visual re-review, P9 screens (2026-11-19)

Independent reviewer (did not build or fix the UI). No application code, CSS, lang, tests or config was changed and nothing was committed. Re-review of `docs/reviews/G7_P9_REVIEW_2026-11-19.md` after fix batch F and sidebar v2. Same method and rubric as `docs/reviews/G7_P8_REVIEW4_2026-11-19.md`: six dimensions (Ref, Vis, RTL, Resp, Sta, Con; 1-5), strict bar mean >= 4.5, PO per-class bar (4.5 with a pack reference = admin dashboard and course page; 4.3 without; every dimension >= 4.0). Scores are visual judgements, not pixel-measured. Screenshots: `tests/Browser/screenshots/G7-P9-review2/<screen>-<ar|en>-<1440|390>.png` (162 files, all recaptured by me; the fixer's `G7-P9-fix1` images were not used as evidence).

The best group is 0.03 below the 4.3 bar.** Thirteen of 14 groups now have every dimension >= 4.0 (was 5). ## Method and environment
- Scratch SQLite DB `rv9.sqlite` in the scratchpad (never `database/database.sqlite`), `migrate --force`, `demo:seed`, `APP_ENV=local`, `CACHE_STORE=file`, `npm run build` run first (ok). Server `php artisan serve --port=8210` with `APP_URL=http://127.0.0.1:8210` (the first start without `APP_URL` left course images pointing at the wrong origin; restarted and recaptured everything). Port 8210 was free (netstat checked). Staff 2FA enabled in the scratch DB only (known TOTP secret).
- Seeded in scratch only: Nour's wishlist (4 courses, direct insert), one "download my data" request through the real form, a view-as session through the real modal, cohort 2 (Animation Lab) capacity set to 1 with one live seat hold so the cohort-full message could be triggered.
- Playwright Chromium (repo `node_modules`), AR and EN, 1440x900 and 390x844, full-page captures, light theme. Every main capture returned HTTP 200 with the expected `dir` and `scrollWidth <= innerWidth` (no page-level horizontal overflow). No 5xx. Capture artefacts (not defects): fixed learner tab bar and sticky bars show mid-page in full-page captures; lazy catalog images in the wishlist are blank in full-page captures.
- Not captured / gaps: `/teach` validation at AR 390 (the form was resubmitted several times and the app returned its 429 page; see X1), `onboarding-agreement` and `onboarding-payout` AR 1440 not opened by me, dark theme, axe, contrast. I looked at roughly 40 of the 162 images in full (EN 1440 and AR 390 for most groups) and used the rest through logged metrics; scores for the unseen captures assume they match their siblings.
