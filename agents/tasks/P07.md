Implements `docs/06_AI_LESSON_ASSISTANT_SPEC.md` v3.0 (M7.2–M7.7). M7.0/M7.1
were delivered in T-P3-10 / T-P3-09. Every task here is `risk: high` and runs

### T-P7-01 — Assistant core pipeline and output guard
- deps: T-P3-09, T-P3-10, T-P4-03
- agents: implementer, test-writer
- size: L
- risk: high
- ai: core — AI spec §5, §7, §8.2, §9
- refs: AI spec §5, §7, §8.2, §8.4, §8.5, §9, §17, PRD §15.2, PRD §15.4, PRD §15.6, ED-009, AI spec §4, AI spec §19
- gates: G1-G6, G8

**Goal** A question in an eligible lesson returns a verified, short, cited answer — or a correct `not_in_source`/`out_of_scope` — streamed to the client.
**Steps**
- [ ] Endpoint `POST /api/v1/lessons/{lesson}/assistant/messages` + `GET .../assistant`; resolve lesson server-side; eligibility check.
- [ ] Context builder: full-context mode (page-tagged approved text, cacheable prefix keyed by document_version) vs chunked mode above threshold (scoped retrieval).
- [ ] Prompt from active `ai_prompt_versions` + style tier + reply language + last 2 turns.
- [ ] Provider call (stream) with 15 s timeout; JSON schema validation; length caps; citation page existence; **quote verification** (normalized fuzzy match on cited page); one retry; safe fallback.
- [ ] SSE: `token` events then final `result`; persist message (status, pages, quote_verified, prompt_version, model, usage).
- [ ] Re-check entitlement + document status immediately before prompt construction.
**Acceptance**
- [ ] A1 Answer with verified quote shown; unverified quote never shown (tests with fake responses).
- [ ] A2 Other lesson's text never in prompt even if client sends another lesson id (test asserts fake provider request).
- [ ] A3 Provider timeout/error returns fallback state; player unaffected (test).
- [ ] A4 Over-length answer trimmed or retried per spec (test).
**Out of scope** Input guards, cache, quota (T-P7-02); UI (T-P7-03).

### T-P7-02 — Input guards, quiz guard, cache and quotas
- deps: T-P7-01, T-P6-01
- agents: implementer, test-writer
- size: M
- risk: high
- ai: core — AI spec §8.1, §8.3, §10
- refs: AI spec §8.1, §8.3, §10, O-015, O-028, PRD §5.3, PRD §15.6, ED-010
- gates: G1-G6, G8

**Goal** Safe, fair and cost-controlled assistant usage.
**Steps**
- [ ] PII masking (phones, emails, national IDs, own name) before provider; opaque student hash.
- [ ] Moderation classification (through adapter; fake in tests) → redirect message or safeguarding route (flag + fixed message; recipients/wording O-028; minors AI off until approved).
- [ ] Injection heuristics → scope reminder.
- [ ] Active-quiz guard: similarity of normalized question vs open graded quiz questions for the learner (keys never used) → page hint + `quiz_guard` event.
- [ ] Per-lesson answer cache (document_version + normalized question + language + style tier; TTL 30 days).
- [ ] Quotas: per student/day, per student/lesson/day, course and global budgets with 80% alert and graceful disable; `429` with reset time.
**Acceptance**
- [ ] A1 Phone/email in question never reaches fake provider (test).
- [ ] A2 Question matching an open quiz item does not get a direct answer (test).
- [ ] A3 Cache hit skips provider and is invalidated by new document version (test).
- [ ] A4 Quota exhaustion returns 429 and UI state (test).
**Out of scope** Semantic cache.

### T-P7-04 — Feedback, help requests and instructor/admin queue
- deps: T-P7-03, T-P5-04
- agents: implementer, ui-builder, test-writer
- size: L
- risk: high
- ai: core — AI spec §12
- refs: AI spec §12, PRD §16, D-019..D-021, Checklist §9, PRD §15.5
- gates: G1-G7
- visual: [Help requests](../../docs/design-system/reference-pack-2026-11-17/09-instructor-help-workspace-v2.png), [Recorded player](../../docs/design-system/reference-pack-2026-11-17/07-recorded-player-ai-v2.png), [Parent dashboard](../../docs/design-system/reference-pack-2026-11-17/08-parent-dashboard-v2.png) · [Implementation and match](../../docs/design-system/reference-pack-2026-11-17/IMPLEMENTATION.md)

**Goal** "Still not understood" creates one help request routed to the responsible instructor with admin copy, resolved inside a platform thread.
**Steps**
- [ ] `help_requests` (unique `ai_message_id`), `help_request_messages`, `help_request_events`; states New → In Progress → Instructor Replied → Waiting for Student → Resolved → Closed.
- [ ] Feedback endpoint (understood/not_understood) idempotent; max 3 open requests per student per lesson.
- [ ] Routing: responsible instructor for course/lesson, else admin queue; notifications (in-app; email optional).
- [ ] Instructor queue (Filament instructor panel) with context: question, AI answer, cited pages, timestamp jump link, PDF page link, reply templates.
- [ ] Admin view of all requests with reassign/intervene; SLA escalation job (default 24 h) marking overdue + admin notice.
- [ ] Student thread UI (`help-request-thread`); parent sees status/replies per policy only.
**Acceptance**
- [ ] A1 Understood creates no request; repeated not-understood taps create one (tests).
- [ ] A2 Instructor of another course cannot see request (test).
- [ ] A3 Overdue escalation fires once (test).
- [ ] A4 Screenshots of student thread and instructor queue AR/EN.
- [ ] G7 (when UI is in scope): capture the implemented screen, compare it with the task reference, and record the result. Resolve unexplained visible differences before closure.
**Out of scope** "Mark as lesson FAQ" (O-AI-01).
