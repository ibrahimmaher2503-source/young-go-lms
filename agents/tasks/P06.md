- agents: implementer, ui-builder, test-writer
- size: M
- risk: normal
- ai: hook — expose open graded questions (text only, no keys) to the quiz guard query
- refs: PRD §12, Checklist §8
- gates: G1-G7
- visual: [Curriculum builder](../../docs/design-system/reference-pack-2026-11-17/03-curriculum-builder.png), [Course wizard](../../docs/design-system/reference-pack-2026-11-17/13-course-wizard-v2.png) · [Implementation and match](../../docs/design-system/reference-pack-2026-11-17/IMPLEMENTATION.md)

**Goal** Instructors build quizzes with supported question types and settings.
**Steps**
- [ ] `questions` (type single/multiple/true_false/short_answer/essay, prompt translatable, points, explanation, order, active, version), `question_options` (text, is_correct, order).
- [ ] Quiz settings: time limit, total marks, pass mark, max attempts, result visibility, randomization flag, progression (after submission / require pass).
- [ ] Filament authoring UI with preview.
**Acceptance**
- [ ] A1 Validation per type (e.g. single-choice exactly one correct) (test).
- [ ] A2 Instructor scoped to assigned courses (test).
- [ ] G7 (when UI is in scope): capture the implemented screen, compare it with the task reference, and record the result. Resolve unexplained visible differences before closure.

- agents: implementer, ui-builder, test-writer
- size: L
- risk: high

**Goal** Learners take quizzes with server-enforced time, attempts, scoring and gating; history immutable.
**Steps**
- [ ] `quiz_attempts` (snapshot of questions/options at start), `quiz_answers`.
- [ ] Start/save/submit Actions; server timer (deadline at start); auto-submit on expiry; scoring; pass/fail; progression gating.
- [ ] Result page respecting visibility; correct answers hidden until allowed; quiz-question and quiz-timer components.
**Acceptance**
- [ ] A1 Submit after deadline rejected/auto-handled (test).
- [ ] A2 Attempt limit enforced (test).
- [ ] A3 Editing questions later does not change past attempts (test).
- [ ] A4 Correct keys never sent to client before allowed (test inspects payload).
- [ ] G7 (when UI is in scope): capture the implemented screen, compare it with the task reference, and record the result. Resolve unexplained visible differences before closure.
**Out of scope** Essay grading UI (T-P6-04 handles review queue).
