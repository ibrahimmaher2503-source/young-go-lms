# P4 — Student learning portal & recorded player

### T-P4-01 — Unified EntitlementService
- deps: T-P3-01, T-P1-04
- agents: implementer, test-writer
- size: L
- risk: high
- ai: hook — AI eligibility consumes EntitlementService; replace AI stub
- refs: DMC §6.1, PRD §17.2, §23 (1–5), Arch §5.2, Conventions §5
- gates: G1-G6

**Goal** One authoritative service that decides learner access for every protected resource.
**Steps**
- [ ] `entitlements` (learner_id, course_id, source_type enum: free, purchase, bundle, subscription, manual_grant, manual_payment, legacy_migration; source_ref; starts_at, ends_at, status active/expired/revoked; granted_by; unique (source_type, source_ref, learner_id, course_id)).
- [ ] Actions `GrantEntitlement` (idempotent), `RevokeEntitlement`, `ExpireEntitlements` (scheduled).
- [ ] `EntitlementService::allows(learner, course|lesson, ability)` handling preview lessons, scheduled lessons, expiry; caches per request.
- [ ] Replace the fail-closed stub from T-P3-08/T-P3-10.
- [ ] Invariant tests I01 (access only via service — arch test: only Entitlements module queries `entitlements`), I03/I04 scaffolds (payment ones filled in P8), I05 manual grant without payment.
**Acceptance**
- [ ] A1 Duplicate grant with same source creates one row (test).
- [ ] A2 Expired/revoked entitlement denies lesson, PDF, AI eligibility (tests).
- [ ] A3 Arch test passes (no direct entitlement queries elsewhere).
**Out of scope** Commerce sources (P8).
