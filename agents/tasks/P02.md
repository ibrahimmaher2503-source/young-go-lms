### T-P2-04 — Catalog, search and filters
- deps: T-P2-01, T-P3-01, T-P1-07
- agents: implementer, ui-builder, test-writer
- size: L
- risk: normal
- ai: none — add nothing AI-related
- refs: YG-WEB-003, YG-GAP-SRCH-001, Design System §5 (Catalog), §4.2 course-card
- gates: G1-G7

**Goal** Published courses discoverable with Arabic-aware search, combinable filters, sort and pagination.
**Steps**
1. `CatalogQuery` (published + visible only): filters discipline/category, age (learner band or manual), level, format (recorded/live/hybrid), content language, instructor, price (free/paid/subscription), availability; sort (newest, popular, price).
2. Search on normalized `search_text` (normalize the query with ArabicNormalizer); DB index strategy documented.
3. `course-card` component (registry), filter panel (drawer on mobile), empty state, pagination; filter state in URL.
**Acceptance**
- A1 "اداء" matches "أداء"; "مسرحيه" matches "مسرحية" (tests).
- A2 Filters combine correctly (dataset test); drafts/pending never listed (test).
- A3 Screenshots AR/EN × mobile/desktop incl. empty state.
**Out of scope** Wishlist button behavior (T-P9-02; render slot only).
